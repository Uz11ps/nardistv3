# Полное руководство: Перевод User Flow из Figma в код

## 🎯 Подход к переносу дизайна

### Шаг 1: Анализ User Flow

Для каждого экрана из Figma определяем:

1. **Тип экрана:**
   - Статический (информация)
   - Интерактивный (формы, кнопки)
   - Динамический (списки, данные)

2. **Компоненты:**
   - Какие переиспользуемые компоненты использовать
   - Какие новые компоненты создать

3. **Состояния:**
   - Загрузка
   - Пусто
   - Ошибка
   - Успех

4. **Навигация:**
   - Откуда приходит пользователь
   - Куда можно перейти
   - Какие данные передавать

### Шаг 2: Создание структуры

#### Пример разбора экрана из Figma:

**Экран: Лидерборд (из вашего дизайна)**
```
Элементы:
- Заголовок "Лидерборд"
- Фильтры (период, режим)
- Список игроков с:
  - Рангом (🥇🥈🥉)
  - Аватаром
  - Именем
  - Рейтингом
  - Статистикой

Компоненты:
- PageHeader ✅

Навигация:
- От: Home, Profile

```

### Шаг 4: Подключение роутинга

В `App.tsx`:
```tsx
import NewScreen from './pages/NewScreen'

// В Routes:
<Route path="/new-screen" element={<NewScreen />} />
```

### Шаг 5: Добавление навигации

В существующих экранах добавить ссылки:
```tsx
<Button onClick={() => navigate('/new-screen')}>
  Перейти к новому экрану
</Button>
```

## 🔄 Процесс работы с Figma

### Для каждого экрана:

1. **Откройте экран в Figma Dev Mode**
2. **Скопируйте:**
   - Размеры элементов
   - Цвета
   - Шрифты
   - Отступы
   - Эффекты
3. **Определите структуру:**
   - Какие компоненты использовать
   - Как организовать layout
4. **Реализуйте:**
   - Создайте компонент
   - Примените стили
   - Добавьте логику
5. **Проверьте:**
   - Сравните с Figma
   - Проверьте навигацию
   - Тестируйте состояния

## 🎨 Применение стилей из Figma

### Метод 1: CSS переменные (рекомендуется)

1. Скопируйте значения из Figma
2. Обновите `frontend/src/styles/figma-tokens.css`
3. Используйте в компонентах:
```tsx
style={{ backgroundColor: 'var(--color-primary)' }}
```

### Метод 2: Inline стили (для специфичных элементов)

```tsx
<div style={{
  // Из Figma → Copy CSS → вставьте сюда
  backgroundColor: '#ff3333',
  padding: '12px 24px',
  borderRadius: '8px',
}}>
```

### Метод 3: CSS модули (для сложных компонентов)

Создайте `ComponentName.css` и импортируйте.

## 🚀 Быстрый старт для нового экрана

1. Скопируйте структуру из `Leaderboard.tsx` или другого похожего

3. Обновите стили из Figma
4. Добавьте роутинг в `App.tsx`
5. Добавьте ссылку в навигацию
6. Тестируйте!

## 💡 Советы

1. **Используйте существующие компоненты** - Card, Button, PageHeader
2. **Создавайте переиспользуемые компоненты** - для повторяющихся элементов
3. **Следуйте паттернам** - структура должна быть похожа на другие экраны
4. **Тестируйте навигацию** - все переходы должны работать
5. **Проверяйте на реальных данных** - не только на заглушках
