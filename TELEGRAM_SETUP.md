# Настройка Telegram Mini App

## Проблема: "Ошибка авторизации"

Если вы видите ошибку "Ошибка авторизации. Убедитесь что вы открыли приложение через Telegram бота", выполните следующие шаги:

## 1. Настройка домена в BotFather

1. Откройте Telegram и найдите бота **@BotFather**
2. Отправьте команду `/mybots`
3. Выберите вашего бота из списка
4. Выберите **"Bot Settings"** → **"Domain"**
5. Введите домен: `nardist.site`
6. Подтвердите

**Важно:** Домен должен быть без `https://` и без `/` в конце!

## 2. Проверка переменных окружения на сервере

Убедитесь что на сервере настроен `TELEGRAM_BOT_TOKEN`:

```bash
cd /var/www/nardiphp
docker-compose exec backend env | grep TELEGRAM_BOT_TOKEN
```

Если токен не настроен, добавьте его в `.env` файл:

```bash
nano .env
# Добавьте строку:
TELEGRAM_BOT_TOKEN=ваш_токен_бота
```

После изменения `.env` перезапустите backend:

```bash
docker-compose restart backend
```

## 3. Проверка через консоль браузера

Откройте приложение через Telegram и откройте консоль разработчика (F12). Проверьте логи:

1. Должно быть: `✅ initData получен, длина: XXX`
2. Если видите `❌ WebApp.initData пустой!` - проблема с настройкой домена в BotFather
3. Если видите ошибку 401 - проблема с токеном или проверкой подписи

## 4. Диагностика на сервере

Проверьте логи backend при попытке входа:

```bash
docker-compose logs -f backend | grep -i "auth\|telegram\|init"
```

Вы должны увидеть детальные логи проверки initData.

## 5. Частые проблемы

### Проблема: initData пустой
**Решение:** 
- Убедитесь что домен `nardist.site` привязан к боту через @BotFather
- Откройте приложение через кнопку бота, а не через прямой URL
- Используйте HTTPS (не HTTP)

### Проблема: "Неверная подпись Telegram initData"
**Решение:**
- Проверьте что `TELEGRAM_BOT_TOKEN` правильный
- Убедитесь что токен соответствует боту, к которому привязан домен
- Перезапустите backend после изменения токена

### Проблема: "Данные авторизации устарели"
**Решение:**
- Закройте и заново откройте приложение через Telegram
- Не используйте старые закладки или прямые ссылки

## 6. Тестирование

После настройки:

1. Откройте вашего бота в Telegram
2. Нажмите на кнопку с Mini App (или отправьте команду `/start` если есть кнопка)
3. Приложение должно открыться без ошибок авторизации

## 7. Проверка работы

Если всё настроено правильно, в консоли браузера вы увидите:
- `✅ initData получен`
- `📤 Отправка запроса на /auth/login...`
- `✅ Авторизация успешна!`

В логах backend вы увидите:
- `🔐 Проверка initData`
- `✅ Hash проверен успешно`
- `👤 Данные пользователя`
