## 🔄 Процесс турнира (BRACKET)

1. **Регистрация**: Участники регистрируются, создаются матчи round 0
2. **Старт турнира**: `startTournament` вызывает `createBracketMatches`
   - Участники распределяются по парам в первом раунде
   - Создаются пустые матчи для следующих раундов
3. **Игра матчей**: Игроки играют матчи текущего раунда
4. **Завершение матча**: `finishMatch` вызывается после завершения игры
   - Определяется победитель
   - Начисляется XP
   - Вызывается `advanceTournament`
5. **Продвижение**: `advanceBracketTournament` проверяет завершение раунда
   - Если все матчи раунда завершены → создаются матчи следующего раунда
   - Победители распределяются по парам
   - Если финальный раунд → турнир завершается
