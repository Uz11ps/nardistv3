# Настройка системы скинов

## Что было реализовано

### Backend

1. **Обновлена структура Skin entity:**
   - Добавлено поле `imageUrl` для изображения скина
   - Добавлено поле `price` для цены в NAR-coin
   - Добавлено поле `rarity` (common, rare, epic, legendary)

2. **Добавлен CRUD для скинов в админ-панели:**
   - `GET /admin/skins` - список всех скинов
   - `POST /admin/skins` - создание скина с загрузкой изображения
   - `PUT /admin/skins/:id` - обновление скина
   - `DELETE /admin/skins/:id` - удаление скина
   - `POST /admin/skins/:id/upload-image` - обновление изображения

3. **Настроена загрузка файлов:**
   - Изображения сохраняются в `backend/uploads/skins/`
   - Статическая отдача файлов через `/uploads/skins/`
   - Поддерживаются форматы: jpg, jpeg, png, gif, webp
   - Максимальный размер: 5MB

4. **Убрана автоматическая инициализация скинов:**
   - Скины теперь создаются только через админ-панель

### Frontend

1. **Создан компонент `SkinSelectModal`:**
   - Модальное окно для выбора скина
   - Отображение изображений, редкости, цены
   - Подсветка выбранного скина

2. **Обновлена страница Shop:**
   - Загрузка скинов из БД
   - Отображение всех скинов в разделе "Косметика"
   - Кнопка "Выбрать скин" открывает модальное окно
   - Покупка и выбор скинов

## Использование

### Создание скина через админ-панель

1. Зайдите в админ-панель (`/admin`)
2. Найдите раздел "Скины"
3. Нажмите "Создать скин"
4. Заполните форму:
   - Название
   - Описание (опционально)
   - Theme (уникальный идентификатор)
   - Board config (JSON с настройками доски)
   - Dice config (JSON с настройками кубиков)
   - Загрузите изображение
   - Укажите цену (если платный)
   - Выберите редкость
   - Укажите вес скина

### Пример boardConfig:
```json
{
  "color": "#D2691E",
  "pattern": "classic"
}
```

### Пример diceConfig:
```json
{
  "color": "#FFFFFF",
  "dotColor": "#000000"
}
```

## API эндпоинты для пользователей

- `GET /skins` - список всех скинов
- `GET /skins/my` - список купленных скинов пользователя
- `GET /skins/selected` - выбранный скин пользователя
- `POST /skins/select` - выбрать скин (тело: `{ skinId: string }`)

## Примечания

- Бесплатные скины (`isDefault: true`) доступны всем
- Платные скины требуют покупки за NAR-coin
- При выборе скина проверяется лимит веса (сила усиления)
- Премиум скины (`isPremium: true`) доступны только с подпиской
