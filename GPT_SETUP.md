# Настройка GPT бота для игры в длинные нарды

## Переменные окружения

Добавьте в файл `.env` на сервере:

```bash
OPENAI_API_KEY=ваш_ключ_openai_api
```

**Важно:** Используйте ваш собственный ключ OpenAI API. Ключ должен начинаться с `sk-proj-`.

## Установка зависимостей

После добавления переменной окружения, пересоберите backend:

```bash
cd /var/www/nardiphp
docker-compose build backend
docker-compose up -d backend
```

## Как работает GPT бот

1. Для длинных нард бот использует GPT-4o-mini для выбора ходов
2. Если GPT недоступен или возвращает ошибку, используется простой алгоритм бота
3. Бот автоматически делает ходы после броска кубиков и после хода игрока

## Проверка работы

После настройки проверьте логи:

```bash
docker-compose logs backend | grep -i gpt
```

Если видите сообщения "GPT returned X moves" - бот работает корректно.
