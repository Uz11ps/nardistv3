# Скрипт для быстрого извлечения стилей из Figma

## Инструкция по использованию

### 1. Откройте Figma Dev Mode
- Нажмите на иконку "Dev Mode" в правом верхнем углу Figma
- Это покажет все измерения и CSS свойства

### 2. Для каждого элемента:

#### Цвета:
1. Выберите элемент
2. В правой панели найдите "Fill" или "Stroke"
3. Скопируйте hex код (например: #ff3333)
4. Добавьте в `frontend/src/styles/figma-tokens.css`

#### Размеры:
1. Выберите элемент
2. В правой панели → Layout → скопируйте Width/Height
3. Используйте в CSS: `width: 100px;` или `width: var(--spacing-6);`

#### Типографика:
1. Выберите текст
2. В правой панели → Text → скопируйте:
   - Font family
   - Font size
   - Font weight
   - Line height
3. Добавьте в `figma-tokens.css` → Typography section

#### Отступы:
1. Выберите элемент
2. В правой панели → Layout → Padding/Margin
3. Используйте значения в компонентах

#### Эффекты (тени, blur):
1. Выберите элемент
2. В правой панели → Effects
3. Скопируйте значения → добавьте в `--shadow-*` переменные

### 3. Автоматизация через плагины

**Figma to React:**
```bash
# В Figma:
1. Плагины → Figma to React
2. Выберите компонент
3. Скопируйте код
4. Адаптируйте под ваш проект
```

**Copy CSS:**
```bash
# В Figma:
1. Выберите элемент
2. Правая панель → Code → CSS
3. Копировать → вставить в CSS файл
```

### 4. Проверка

После применения стилей:
1. Откройте страницу в браузере
2. Chrome DevTools → Overlay
3. Сравните с Figma дизайном
4. Исправьте расхождения
