# Улучшения игры в нарды

## Текущие проблемы

1. **Упрощенная логика игры** - не все правила нард реализованы
2. **Визуализация** - доска работает, но нужно улучшить UX
3. **Валидация ходов** - базовая валидация есть, но не все случаи обработаны

## Что нужно улучшить

### 1. Полная реализация правил коротких нард

**Текущее состояние:**
- Базовая валидация ходов
- Обработка баров
- Выведение шашек (bear off)

**Что добавить:**
- [ ] Правила для дубля (double) - когда выпадают одинаковые кубики (2-2, 3-3 и т.д.)
- [ ] Обязательность хода всеми кубиками если возможно
- [ ] Блокировка (prime) - когда 6 точек подряд заняты
- [ ] Правило "hit" - когда шашка противника съедается
- [ ] Правило "gammon" и "backgammon" для подсчета очков
- [ ] Правила для удвоения ставок (doubling cube)

### 2. Улучшение движка игры

**Файлы для изменения:**
- `backend/src/games/game-engine/backgammon-engine.ts`
- `backend/src/games/game-engine/long-backgammon-engine.ts`

**Что добавить:**
- [ ] Проверка всех возможных ходов для текущего состояния доски
- [ ] Алгоритм выбора оптимального хода для ботов
- [ ] Проверка валидности всех ходов перед применением
- [ ] Логика окончания игры (все шашки выведены)

### 3. UX улучшения

**Файлы для изменения:**
- `frontend/src/components/BackgammonBoard.tsx`
- `frontend/src/pages/Game.tsx`

**Что добавить:**
- [ ] Подсветка возможных ходов при клике на шашку
- [ ] Анимация ходов
- [ ] Индикация текущего игрока
- [ ] Отображение кубиков крупнее
- [ ] Индикация обязательных ходов

### 4. Визуализация в истории и админ панели

**Уже реализовано:**
- ✅ Реплей игр в истории
- ✅ Визуализация ходов для премиум пользователей
- ✅ Просмотр игр в админ панели

**Что можно улучшить:**
- [ ] Автоматическое проигрывание реплея
- [ ] Скорость проигрывания
- [ ] Комментарии к ходам

## Приоритеты

1. **Высокий приоритет:**
   - Полная валидация ходов
   - Правила для дубля кубиков
   - Обязательность использования всех кубиков

2. **Средний приоритет:**
   - UX улучшения (подсветка ходов, анимация)
   - Улучшение AI для ботов

3. **Низкий приоритет:**
   - Удвоение ставок (doubling cube)
   - Расширенные правила (gammon, backgammon)
