## API Endpoints

### Кланы
- `GET /clans` - список кланов с фильтрами
- `GET /clans/:id` - информация о клане
- `GET /clans/:id/members` - участники клана
- `POST /clans/create` - создать клан
- `POST /clans/:id/join` - вступить в клан
- `POST /clans/:id/leave` - покинуть клан
- `POST /clans/:id/contribute` - внести вклад
- `POST /clans/:id/upgrade` - улучшить клан

### Игры
- `GET /games/:id` - состояние игры
- `POST /games/create-bot` - создать игру с ботом

### История
- `GET /history` - история игр с фильтрами
- `GET /history/replay/:gameId` - реплей игры
- `GET /history/export/:gameId/json` - экспорт JSON
- `GET /history/export/:gameId/csv` - экспорт CSV

## WebSocket Events

### Игра
- `game:join` - присоединиться к игре
- `game:update` - обновление состояния игры
- `game:move` - ход сделан
- `game:dice` - брошены кубики
- `game:finished` - игра завершена
- `game:roll-dice` - бросить кубики
- `game:move` - сделать ход

### Матчмейкинг
- `matchmaking:join` - начать поиск
- `matchmaking:leave` - отменить поиск
- `matchmaking:found` - найден соперник
