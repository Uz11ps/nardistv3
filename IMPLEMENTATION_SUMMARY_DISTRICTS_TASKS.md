# Реализация захвата районов и системы заданий

## ✅ Реализовано

### 1. Захват районов кланами

#### Сущности:
- ✅ `DistrictCapture` - entity для отслеживания захваченных районов
- ✅ Используется существующий `DistrictConfig` для конфигурации районов
- ✅ Обновлен `Clan` entity (уже есть поле `ownedDistricts`)

#### Сервисы:

- ✅ `CityService.getClanDistricts()` - получение захваченных районов клана
- ✅ `CityService.collectDistrictIncome()` - сбор дохода с района

- ✅ `ClansService.captureDistrictForClan()` - обертка для захвата через клан

#### Endpoints:
- ✅ `POST /api/clans/:id/territories/capture` - захват района (теперь принимает `districtCode` вместо `buildingType`)
- ✅ `GET /api/clans/:id/districts` - получить захваченные районы клана
- ✅ `POST /api/clans/:id/districts/:districtCode/collect` - собрать доход с района
- ✅ `GET /api/city/districts` - получить все районы
- ✅ `GET /api/city/districts/available-for-capture` - получить доступные районы для захвата

### 2. Система заданий курсов

#### Сущности:
- ✅ `CourseTask` - задания курсов с типами:
  - `TRAIN_WITH_BOT` - тренировка с ботом
  - `ONLINE_MATCH` - онлайн-партия 1х1
  - `VIEW_CITY` - просмотр экрана "Город"
  - `PLAY_SHORT_MATCH` - быстрая партия (короткие нарды)
  - `PLAY_LONG_MATCH` - длинная партия
  - `WIN_MATCH` - победа в матче
  - `COMPLETE_TRAINING_POSITION` - пройти тренировочную позицию
  - `JOIN_CLAN` - вступить в клан
  - `PURCHASE_BUILDING` - купить строение
  - `UPGRADE_BUILDING` - улучшить строение
  - `CUSTOM` - кастомное задание

- ✅ `CourseTaskProgress` - прогресс выполнения заданий пользователем

#### Сервисы:
- ✅ `CourseTasksService` - сервис для работы с заданиями:
  - `getCourseTasks()` - получить задания курса с прогрессом
  - `createTask()` - создать задание (только админы)
  - `updateTaskProgress()` - обновить прогресс задания
  - `claimTaskReward()` - получить награду за задание
  - `getOnboardingTasks()` - получить онбординговые задания

#### Endpoints:
- ✅ `GET /api/academy/courses/:courseId/tasks` - получить задания курса
- ✅ `POST /api/academy/courses/:courseId/tasks` - создать задание (только админы)
- ✅ `POST /api/academy/tasks/:taskId/progress` - обновить прогресс задания
- ✅ `POST /api/academy/tasks/:taskId/claim` - получить награду за задание
- ✅ `GET /api/academy/onboarding/tasks` - получить онбординговые задания

## 🔧 Технические детали

### Захват районов:
- Район захватывается на 24 часа
- Один клан может захватить несколько районов
- Доход с района собирается ежедневно
- Доход добавляется в казну клана

### Задания:
- Задания могут быть обязательными (`isRequired: true`) или опциональными
- Онбординговые задания помечаются флагом `isOnboarding: true`
- Прогресс отслеживается через `CourseTaskProgress`
- Награды выдаются только после явного запроса (`claimTaskReward`)

## 📝 Примечания

- Старая логика захвата строений оставлена для обратной совместимости (помечена как `@deprecated`)
- Новые endpoints используют `districtCode` вместо `buildingType`
- Задания могут быть добавлены как к курсам, так и как отдельные онбординговые задания
